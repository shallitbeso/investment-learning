防骗与风险警示

投资骗局的受害者从来不只是"不懂的人"，很多是受过高等教育、有一定积蓄的人。学会识别骗局，比学会赚钱更重要——被骗的钱几乎不可能追回。

1. 识别骗局的黄金法则

出现以下任意一条，请立即远离
  • 承诺保本保息、高收益：正规机构不允许承诺保本保收益（存款和储蓄国债除外）；
  • 拉人头有奖励：发展下线就能获得返利，这是传销和庞氏骗局的典型特征；
  • 陌生人主动带你赚钱：网友、"导师"、群主主动拉你投资；
  • 要求转账到个人账户：正规投资的资金只会进入你自己名下的券商资金账户或基金公司 / 托管银行账户；
  • 使用非正规 App：通过链接或二维码下载、在官方应用商店搜不到的"交易平台"；
  • 制造紧迫感："名额有限""今天最后一天""错过再等十年"；
  • 出金困难：小额可以提现，大额提现时要求先交"手续费""保证金""税费"；
  • 说不清钱是怎么赚的：用"区块链""元宇宙""AI 量化""海外项目"等时髦概念包装，却说不清盈利模式。

2. 常见骗局类型

① 荐股群 / 直播间骗局

流程通常是：通过短视频、广告或陌生好友把你拉进"股票交流群"→ 群里"老师"免费荐股，"群友"（多为托）天天晒收益 → 推销付费 VIP 服务，或引导你下载某个"内部交易平台"参与"打新""机构席位""原始股"→ 你在虚假平台上看到盈利，越投越多 → 最终无法提现，平台消失。

另一种变体是"杀猪盘"：骗子先以恋爱、交友身份长期培养感情（"养猪"），再引诱你投资（"杀猪"）。

② 庞氏骗局

用后来投资者的钱支付早期投资者的"收益"，制造赚钱假象。一旦新资金流入放缓，就会崩盘。特征：收益异常稳定且高、强调拉新人、说不清投资去向。历史上的 P2P 暴雷潮、各种"理财平台"，很多都是这种模式。

③ 虚假交易平台

冒充正规券商、期货公司、外汇平台，甚至仿冒知名机构的名称和界面。你看到的"行情"和"盈利"都是后台随意修改的数字。

④ 原始股 / 股权众筹骗局

声称"公司即将上市，原始股翻百倍"。真正有价值的上市前股权，几乎不会面向陌生散户推销。

⑤ 虚拟货币骗局

空气币、虚假交易所、"矿机托管"、"挖矿理财"、"稳定币高息存款"等。国内对虚拟货币相关业务有明确限制，参与这些活动不受法律保护。

⑥ 冒充客服 / 冒充监管

冒充券商或基金公司客服，以"账户异常""注销账户""退还费用"为由，诱导你转账或泄露验证码；甚至冒充证监会、公安，声称你的账户涉案需要"资金核查"。证监会和公安绝不会要求你转账到"安全账户"。

⑦ 养老诈骗 / 高息"理财"

以"养老项目""以房养老""保健品投资"等形式针对中老年人。提醒你的家人也要注意。

⑧ "带单""代客理财"

要求你把账户密码交给他人操作，承诺收益分成。这本身就是违法行为，账户可能被用来"对倒"拉抬股价（坐庄出货给你），损失由你承担。

3. 如何核实机构资质

想核实去哪里查
证券公司、基金公司、期货公司是否合法中国证监会官网"机构名录"；中国证券业协会、中国证券投资基金业协会（"中基协"）、中国期货业协会官网
某个人是否具有从业资格中国证券业协会"从业人员信息公示"、中基协"从业人员公示"
私募基金管理人中基协"私募基金管理人公示平台"
银行、保险机构国家金融监督管理总局官网
App 是否正规只从手机官方应用商店下载，并核对开发者是否为该机构本身
最简单的原则

只在正规券商的官方 App 里交易股票和场内基金；只通过银行、正规基金销售平台或基金公司官方渠道购买基金。永远不要把钱转给任何个人。

4. 合法但高风险的陷阱

有些产品本身合法，但新手容易在不理解的情况下买入并亏损：

  • 结构复杂的理财产品：如挂钩某些指数的"雪球"类结构化产品，在特定情况下可能大幅亏损；
  • 杠杆和反向 ETF：适合短期交易，长期持有会因"波动损耗"而偏离预期；
  • 融资融券：大跌时可能被强制平仓；
  • 期货期权：第 16 章详解；
  • 储蓄型 / 投连型保险：前期退保损失大，不适合需要流动性的资金；
  • "保本"误导：银行网点销售的保险、代销私募产品被包装成"存款"，签字前务必问清楚。
原则

不懂不买。如果你不能用三句话向别人解释一个产品是怎么赚钱、在什么情况下会亏钱，就不要买它。

5. 如果不幸被骗了

  1. 立即停止转账，不要再交任何"解冻费""手续费"；
  2. 保留证据：聊天记录、转账记录、App 截图、网址、对方账号；
  3. 立即报警：拨打 110 或到当地派出所报案，越早越有可能冻结资金；可以拨打 96110 反诈专线咨询；
  4. 向监管投诉：涉及证券期货的，可拨打证监会投资者服务热线 12386；
  5. 警惕"二次诈骗"：声称能帮你"追回损失"的"律师""黑客"多数也是骗子。

建议在手机上安装国家反诈中心 App，它可以识别部分诈骗电话和链接。
